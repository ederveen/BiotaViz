# BiotaViz

BiotaViz is a microbiome compositional data standard which offers a convenient human readable format over multiple phylogenetic levels, while also providing machine readable compatibility with other standards such as BIOM through various modules and extensions.

## Earlier work

The BiotaViz standard is based on earlier work by <i>Michiel Westenberg et al., 2014</i>, from the University of Technology Eindhoven, which was published as a poster at the VIZBI conference for Visualizing Biological Data. The poster describes BiotaViz as a tool for large-scale comparison and visualization of microbial community composition with navigable taxonomy and abundance heat maps. The concept of BiotaViz had earlier been implemented as part of visual analytics techniques as outlined in the Computer Graphics Forum journal.<br>
